# Терминал, файлы и макросы

После деплоя новой версии один раз выполните на VPS:

```bash
sudo bash /opt/server-dashboard/current/scripts/enable-console.sh
```

Скрипт устанавливает обновлённый systemd unit, создаёт `/var/lib/server-dashboard` для макросов и копий файлов, устанавливает `tmux` и перезапускает сервис. Проверьте результат:

```bash
curl http://127.0.0.1:5100/api/console/status
sudo systemctl status server-dashboard.service
```

В ответе API поле `privileged` должно быть `true`. До запуска скрипта сайт продолжит показывать метрики, но терминал не сможет выполнять `sudo`, а запись файлов и макросов будет ограничена правами старого пользователя сервиса. После обновления unit приложение работает от `root`, поэтому терминал, редактор и макросы получают полный доступ к VPS через уже существующий пароль сайта в Caddy. Приложение по-прежнему слушает только `127.0.0.1:5100`.

## Как пользоваться

- Откройте `/terminal` через кнопку «Терминал» в левом меню Workspace. На этой странице терминал принимает обычный ввод Bash. Поле под ним отправляет команду в терминал; запись `/имя` запускает сохранённый макрос.
- Вкладка «Файлы» открывает каталоги по абсолютному пути. Редактор поддерживает вкладки, подсветку, поиск и замену (`Ctrl+F`), сохранение (`Ctrl+S`). Файлы должны быть UTF-8 и не больше 4 МБ. При каждом изменении существующего файла предыдущая версия сохраняется в `/var/lib/server-dashboard/backups` и доступна через список «Копии».
- Во вкладке «Макросы» можно задать командный текст Bash, путь к исполняемому файлу и адрес сайта для открытия после успешного выполнения. Команда выполняется первой, затем файл, затем в браузере открывается адрес. Макросы хранятся в `/var/lib/server-dashboard/macros.json` и остаются после деплоя.
- Пример `/flush` очищает DNS-кеш **на VPS** командой `sudo resolvectl flush-caches`, затем открывает адрес сайта в новой вкладке вашего браузера. Это не очищает DNS-кеш вашего компьютера. Адрес и команду можно изменить в форме макроса.
- Терминал использует `tmux`: при переподключении к той же работающей службе сессия сохраняется.

Для разработки на Windows сайт и редактор работают локально, но PTY-терминал доступен только на Linux.
